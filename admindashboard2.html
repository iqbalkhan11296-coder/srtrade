BACKUP & RESTORE

Export or restore all SR TRADE LINK dashboard records

Export complete backup

Combines the browser IndexedDB archive with all current Supabase records into one complete JSON file. After the JSON backup is created and archived in this browser, confirm to clear the five Supabase transaction tables. The dashboard verifies that each is empty. Master tables are protected.

Import backup to browser

Choose a backup JSON file. Its records are merged into this browser's IndexedDB archive only. Nothing is uploaded to or deleted from Supabase.

No backup file selected.

New records continue to save in Supabase. Historical records remain in IndexedDB. All dashboard views combine both sources. Keep a copy of each downloaded JSON file somewhere safe.
